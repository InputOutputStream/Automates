📋 Instructions d'utilisation

  • + pour l'union (ex: a+b)
  • * pour l'étoile de Kleene (ex: a*)
  • () pour les groupements (ex: (a+b)*)
  • ε pour l'expression vide
  • ∅ pour le langage vide
  • La concaténation est implicite (ex: ab)
